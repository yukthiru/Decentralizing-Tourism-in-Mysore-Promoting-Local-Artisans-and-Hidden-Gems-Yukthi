Simply follow these 3 steps to add images to your Mysore Unseen application:

================================================================================
STEP 1: VERIFY SETUP
================================================================================

Ensure you're in the project directory:
    cd path/to/mysore-unseen

Verify Python is installed (3.6+):
    python --version

Install dependencies:
    pip install -r requirements.txt

================================================================================
STEP 2: INITIALIZE DATABASE
================================================================================

This creates the SQLite database with 70+ items (artisans, food, products, etc.):

    python seed_data.py

Expected output:
    ✓ Dropping existing tables...
    ✓ Creating fresh tables...
    ✓ Seeding Obscure Hidden Gems & Locations...
    ✓ Seeding Real Artisans...
    ✓ Seeding Authentic Artisan Products...
    ✓ Seeding Obscure Local Food Discoveries...
    ✓ Database fully seeded with real Mysore data!

Time: ~1-2 minutes

================================================================================
STEP 3: FETCH IMAGES FROM GOOGLE
================================================================================

This is the main step - fetches 50+ images from Google and updates database:

    python update_images_from_google.py

What happens:
    1. Script starts and initializes
    2. For each artisan:
       - ⬇ Searches Google Images
       - ✓ Downloads image
       - ✓ Updates database
    3. For each food establishment:
       - ⬇ Searches Google Images
       - ✓ Downloads image
       - ✓ Updates database
    4. Same for: Products, Hidden Gems, Market Stalls

Expected output:
    ====================================================================
    MYSORE UNSEEN - IMAGE UPDATE FROM GOOGLE
    ====================================================================
    Database: .../mysore_unseen.db
    Images Directory: .../static/images
    
    ====================================================================
    UPDATING ARTISAN IMAGES
    ====================================================================
    
    [1] KSIC Silk Weavers (Mysore Silk Weaving)
      ⬇ Fetching: KSIC Silk Weavers Mysore Silk Weaving artisan craftsperson
      ✓ Database updated
    
    [2] Sri Krishna Murthy & Team (Rosewood Inlay Art)
      ⬇ Fetching: Sri Krishna Murthy & Team Rosewood Inlay Art artisan Mysore
      ✓ Database updated
    
    ... (continues for all items)
    
    ====================================================================
    ✓ ALL IMAGES UPDATED SUCCESSFULLY!
    ====================================================================

Time: 15-20 minutes (includes 1.5s delays between requests)

Success indicators:
    - 50+ JPG files in static/images/ directory
    - Each file is 10-100 KB in size
    - Database records updated with /static/images/ URLs
    - No ✗ marks in output (all items fetched)

================================================================================
IF IMAGES AREN'T SHOWING
================================================================================

Try these fixes in order:

1. Hard Refresh Browser:
   Windows: Ctrl+Shift+R
   Mac: Cmd+Shift+R
   
2. Clear Browser Cache:
   Chrome: Settings → Privacy → Clear browsing data
   Firefox: History → Clear Recent History
   
3. Restart Flask App:
   - Press Ctrl+C to stop the running app
   - Run: python app.py
   - Refresh browser
   
4. Check Images Were Downloaded:
   - Stop Flask (Ctrl+C)
   - Check: dir static\images\*.jpg
   - Should show 50+ files
   
5. Re-fetch Images:
   - Stop Flask
   - Run: python update_images_from_google.py
   - This will overwrite and re-download if needed
   - Then run: python app.py again
