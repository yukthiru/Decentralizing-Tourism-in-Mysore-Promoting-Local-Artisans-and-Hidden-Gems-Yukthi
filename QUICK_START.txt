================================================================================
MYSORE UNSEEN - ADD IMAGES TO ARTISANS & FOOD DISCOVERY
================================================================================

QUICK START (3 Steps):

1. SEED DATABASE (if not already seeded):
   python seed_data.py

2. FETCH IMAGES FROM GOOGLE:
   python update_images_from_google.py
   
   This will:
   - Fetch images for 6 artisans
   - Fetch images for 18 food establishments
   - Fetch images for 14 products
   - Fetch images for 13 hidden gems
   - Fetch images for 6 market stalls
   - Update database with image URLs
   Time: ~15-20 minutes

3. RUN APPLICATION:
   python app.py
   
   Then open: http://localhost:5000/artisans
              http://localhost:5000/food-discovery

TROUBLESHOOTING:

Q: Database doesn't exist?
A: Run: python seed_data.py

Q: Images not downloading?
A: Check internet connection and try again

Q: Images not showing on website?
A: Hard refresh browser (Ctrl+Shift+R)

Q: Want to retry failed downloads?
A: Update the script line to add --overwrite (see RUNNING_IMAGE_SCRIPTS.md)
